# BerberOS
Berber işletmeleri için mobil uyumlu randevu, işlem, tahsilat ve çalışan raporlama MVP'si.

## Stack
- React + TypeScript + Vite
- Supabase Auth + Postgres + Row Level Security
- Responsive desktop/mobile interface

## Başlangıç
Detaylı kurulum için `SETUP.md` dosyasını okuyun.

```bash
cp .env.example .env
npm install
npm run dev
```

Supabase SQL şeması: `supabase/schema.sql`.
